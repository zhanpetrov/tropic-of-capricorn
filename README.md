# TROPIC OF CAPRICORN — Henry Miller | Interactive Contraband Edition

An interactive 1939 Obelisk Press literary sanctuary for Henry Miller's *Tropic of Capricorn* ("On the Ovarian Trolley").

- **Live Website:** <https://zhanpetrov.github.io/tropic-of-capricorn/>
- **Repository:** <https://github.com/zhanpetrov/tropic-of-capricorn>

---

## Features

1. **I. Annotated Movements** — Curated symphonic passages with interactive historical marginalia, automatic typewriter cadence playback, adjustable typography, and three reading themes (*Obelisk 1939*, *Brooklyn Noir*, and *Villa Seurat*).
2. **II. Unabridged PDF Reader & Bookmark Tracker** — Same-origin embedded unabridged PDF (`tropic-of-capricorn.pdf`, 216 folio pages / 348 book pages) with persistent `localStorage` page bookmarks and quick landmark jumps.
3. **III. 1920s NYC Psychogeography Map** — Interactive vector blueprint mapping Williamsburg's 14th Ward, the Cosmodemonic Telegraph HQ, Wilson's/Roseland Dance Hall on Broadway, the Ovarian Trolley, Brooklyn Heights, and Coney Island.
4. **IV. Contraband Notebook & Automatic Writing Studio** — Stream-of-consciousness typewriter studio with live WPM cadence counter, Web Audio telegraph key & 1927 Brooklyn Nocturne ambient drone, and `.TXT` marginalia export.
